# Mappatura delle proprietà custom

Tutti i nomi Hunt_* sono convenzioni locali. Verifica tipo e significato sul raw: attore/soggetto, client/proxy e valori action vendor. Il progetto non installa proprietà.

| Proprietà | Tipo / significato |
|---|---|
| Hunt_Action | Stringa: valori canonici allow/deny/drop/blocked |
| Hunt_CommandLine | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_DNSName | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_DNSRcode | Stringa canonica, es. NXDOMAIN |
| Hunt_DNSType | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_EventID | Stringa Windows EventID del provider/canale corretto |
| Hunt_HTTPHost | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_Image | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_K8sObject | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_K8sResource | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_K8sSubresource | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_K8sVerb | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_LogonType | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_Method | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_ParentImage | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_PostNATSrc | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_PreNATSrc | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_ProcessGuid | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_Result | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_ServiceName | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_SessionID | Identificatore sessione con scope; proteggere i token |
| Hunt_Status | HTTP status come stringa |
| Hunt_TargetFilename | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_TargetImage | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_TargetUser | Soggetto dell’operazione, distinto dall’attore |
| Hunt_URI | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_UserAgent | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
| Hunt_WAFRule | Stringa o tipo compatibile documentato localmente; verificare estrazione e NULL |
